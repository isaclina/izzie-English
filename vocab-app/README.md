# Izzie 중등 영단어

중학교 기본 영단어 90개(3개 유닛 × 30단어)를 학습하는 웹 앱입니다. `index.html` 파일 하나로 동작하며, 크롬이나 사파리에서 열면 됩니다.

- **단어 학습 (5단계)**: ① 단어와 뜻 → ② 발음 듣고 따라하기 (크롬에서는 🎤 음성 인식으로 발음 확인) → ③ 동의어 듣기 → ④ 단어가 들어간 문장 듣기 → ⑤ 문장 듣고 쓰기
- **Review 1–3**: 유닛별 단어 쓰기, 문장 쓰기 (10/20/30문항, 틀린 문제만 다시 풀기)
- **원어민 음성 녹음 포함**: `audio/` 폴더에 단어·동의어·예문 MP3 270개가 들어 있습니다. 🐢 버튼은 같은 녹음을 천천히 재생합니다. 파일이 없으면 브라우저 음성으로 읽어 줍니다.
- 진도와 최고 점수는 브라우저에 저장됩니다.

## 내 컴퓨터(D 드라이브)에서 쓰기

1. `izzie-vocab-app.zip`을 내려받아 `D:\` 에 압축을 풉니다.
2. `D:\izzie-vocab-app\index.html` 을 크롬으로 엽니다. `audio` 폴더는 `index.html` 옆에 그대로 두세요.

단어를 바꾸려면 (새 단어는 녹음 파일이 없으니 브라우저 음성으로 재생됩니다) `index.html` 안의 `UNITS` 배열에서 `[단어, 품사, 뜻, 동의어, 예문, 예문 해석]` 항목을 수정하세요.
