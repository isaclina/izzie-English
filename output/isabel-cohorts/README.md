|---|---|---|
| 2020 중1 반 (김건희 반) | 김건희, 안도후, 안동휘, 나민하 | 2020 중1 → 2022 중3 (수능까지) |
| 2023 중1 반 (구성관 반) | 구성관, 송지효, 신준섭, 박주연 | 2023 중1 → 2025 중3 3차(고3) |

- `이사벨반_성적분석.pptx` — 발표용 16장 (요약, 반 비교, 반별 총점·듣기독해·학생별/내신)
- `이사벨반_성적분석.xlsx` — 반별 시트(입력값 + 계산식 + 차트), 반 비교 시트, 안내
- `data.json` — 성적표 사진에서 옮긴 원자료 (`build_data.py`로 생성)
- `build_xlsx.py`, `build_pptx.js` — 파일 생성 스크립트

## 시험 수준별 성적 변화 (반별 엑셀)

`build_level_xlsx.py A|B|C`로 생성. 시트: 안내, 요약, 고1 모의고사, 고2 모의고사, 고3 모의고사·수능(있는 경우). 각 시트에 듣기·독해·총점 표와 학생별 꺾은선 그래프.

- `김건희반_시험수준별_성적.xlsx` — 고1 7회, 고2 4회, 고3·수능 2회
- `구성관반_시험수준별_성적.xlsx` — 고1 7회, 고2 4회 (고3 자료 없음)
- `이서연반_시험수준별_성적.xlsx` — 고1 3회, 고2 1회

## 총점 성장 (반별 엑셀)

`build_total_xlsx.py A|B|C`로 생성. 총점만 사용해 고1 / 고2 / 고3+수능 그룹으로 나눔.

- 요약 시트: 학생별·반 평균의 그룹 평균 총점(계단 그래프)과 설명
- 그룹 시트: 시험별 총점, 첫 시험 → 마지막 시험 변화, 반 평균 굵은 선 그래프, 첫 vs 마지막 막대 그래프, 설명
